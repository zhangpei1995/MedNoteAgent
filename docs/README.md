## 当前功能说明

当前实现以根目录 README 为准，已经具备：

- Spring Boot 3 后端服务。
- SQLite 会话与轮次审计表。
- 会话提交、会话列表、会话轮次和轮次状态查询接口。
- 事务提交后异步执行 Agent 的正式链路。
- DashScope 模型调用与执行结果回写。
- Vite + React 前端对话工作台。

本文档中心暂不重复接口细节，避免两处文档漂移。涉及启动方式、当前功能和近期工作，优先阅读 [根目录 README](../README.md)。

## 近期文档工作

近期只补和当前功能直接相关的文档：

1. 会话接口说明
   - 梳理请求参数、响应字段、状态值和错误语义。
   - 等接口状态稳定后再创建独立文档。

2. 轮次审计说明
   - 说明 `chat_turn_audit` 中模型请求、模型响应、系统提示词、错误信息和耗时字段的含义。
   - 结合医学安全要求，补充证据引用字段或结构化保存方案。

3. 药品说明书处理说明
   - 先围绕现有两份 PDF 说明资料来源、抽取边界和人工校验要求。
   - 明确哪些内容可以进入回答证据，哪些内容只能作为原始参考资料保留。

4. 前端对话状态说明
   - 记录等待、执行中、完成、失败等状态的展示规则。
   - 和后端状态字段保持一致。

这些文档在方案明确、对应文件创建后，再加入本索引。

## 文档维护规则

- 新功能文档应在功能设计明确后再创建，避免保留占位链接或不存在的路径。
- 新增 README、目录树、推荐阅读顺序、文档索引或链接清单前，必须先用 `rg --files` 或等价方式核对真实文件。
- 原始资料放入 `docs/reference/`；运行生成数据放入 `data/`，不要和文档混放。
- 文档只描述当前代码已经具备的能力和近期明确要做的工作，不提前铺开过大的长期规划。

## 命名规则

- 新增 Markdown 文档统一使用小写英文和中划线命名。
- 稳定项目文档放入对应分类目录，不放在仓库根目录。
- 需要描述后续工作但尚未落地文件时，在当前文档中写清任务，不提前创建空链接。
